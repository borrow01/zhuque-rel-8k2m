## 使用说明（一看就会）

给第一次使用的朋友 · 三步上网

① 填激活码　→　② 等出现绿色 ✅　→　③ 点「连接」

### 一、第一次：输入激活码

打开后弹出激活框，粘贴你的激活码（形如 `ZHUQUE-XXXX-XXXX`），点「激活」等几秒即可。

### 二、打开请先等 10~30 秒（重要）

软件在为你这台电脑匹配最快节点、自动测速，属正常现象，不是卡死。
等节点列表出现绿色 ✅ 再连，上网最稳（灰色＝暂不可用，跳过）。

> 截图参考：节点列表——出现绿色 ✅ 再连

### 三、点连接 / 断开

点「连接」，底部状态栏显示 `● 已连接 · 线路名` 就上网了。
不用时点「断开」，状态栏变「未连接」，本机网络恢复。

> 截图参考：状态栏 `● 已连接`

### 四、注意事项

- **自动换线**：连上不好用，软件会自动换其它线路继续试，不用你手动断开重来。
- **私密使用**：节点别公开转发、别刷流量，避免 IP 被封。
